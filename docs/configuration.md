# Documentation setup

Use Python 3.11 or newer for documentation checks. No database, model provider, Node server or credentials are needed. The application configuration is documented in the separate StaffFlow repository.

When adding a historical artifact, preserve authorship and its original date. Index it in README.md and run python3 scripts/update-inventory.py, then both documentation checks. Empty files remain explicitly marked as placeholders. Do not invent missing meetings, outcomes or citations.
